## Ganti Tema Terang dan Gelap dengan Mudah

Fitur **Mode Gelap** memungkinkan guru dan staf untuk mengubah tampilan aplikasi menjadi tema gelap. Fitur ini membantu mengurangi kelelahan mata, terutama saat menggunakan aplikasi di malam hari atau di lingkungan dengan pencahayaan rendah.

<img src="/images/page/78_darkmode.jpg" alt="Pilihan Mode Gelap" className="w-full max-w-sm max-h-100 object-contain mx-auto mb-6" />


### 1. Cara Mengaktifkan Mode Gelap

1. Buka aplikasi **eSchool Mobile - Guru & Staf**.
2. Masuk ke halaman **Profil**.
3. Ketuk menu **Tampilan Aplikasi**.
4. Pilih salah satu opsi yang tersedia:
   - **Terang**
   - **Gelap**
   - **Ikuti Sistem**

### 2. Pilihan Tema

- **Terang** — Tema terang default
- **Gelap** — Latar belakang gelap untuk kenyamanan di kondisi cahaya rendah
- **Ikuti Sistem** — Secara otomatis mengikuti pengaturan tema perangkat

### 3. Manfaat Menggunakan Mode Gelap

- Mengurangi kelelahan mata saat digunakan di malam hari
- Menghemat daya baterai pada perangkat dengan layar OLED
- Memberikan pengalaman membaca yang lebih nyaman
- Memberikan tampilan yang modern dan profesional

### 4. Perubahan Langsung Berlaku

Setelah Anda memilih tema, perubahan akan langsung diterapkan ke seluruh aplikasi tanpa perlu me-restart aplikasi.
